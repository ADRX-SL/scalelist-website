## This page never existed before

Nobody opened WordPress to make this. It was created by adding one file to the
**scalelist-website** repository and merging the pull request.

### What that means for you

- Write a file, open a PR, merge it — the page appears in WordPress
- Edit the same file later and the same page updates, no duplicate
- Everything is reviewable and revertable, because it is all in git
- It stays a draft until someone chooses to publish it

Safe to delete whenever you like.
