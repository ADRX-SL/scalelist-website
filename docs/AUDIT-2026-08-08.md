# Infrastructure audit — 2026-08-08

## How the pieces actually connect

```
Lovable (73 projects)  ──manual export──▶  GitHub (64 repos, 1 per page)
                                                  │
                                          (read by a developer)
                                                  ▼
Cloudflare (zone scalelist.com, proxied) ──▶ SiteGround (34.1.143.141 = c1131935.sgvps.net)
                                                  │
                                          WordPress + Elementor Pro
                                          + JetEngine + ACF Pro
```

Verified facts:

- **DNS**: `scalelist.com` A → `34.1.143.141`, proxied through Cloudflare. That IP is the SiteGround host `c1131935.sgvps.net`. SSL mode `full`, Always-Use-HTTPS `on`.
- **Cloudflare**: zone on the Free plan. **No Workers, no Workers routes, no Pages projects** existed before this work — Cloudflare is pure DNS + CDN + WAF today.
- **No repo was ever deployed anywhere.** No CI, no build hooks, no Cloudflare/Vercel/Netlify connection on any repo. The GitHub repos were only ever read by hand.
- **WordPress is the only thing serving the site.** Pages are Elementor layouts + ACF fields stored in MySQL; ~35k programmatic pages are generated by 8 custom mu-plugins.

## The gap nobody had noticed

**44 of 73 Lovable projects are published. Only 8 have a GitHub repo.**

36 published Lovable designs exist *only inside Lovable* — no repo, no backup, no version history. Among them: `scalelist-vs-apollo`, `scalelist-vs-findymail`, `pseo-yc-directory`, `usa-public-listed-companies`, `yc-founders`, `clutch-lead-generation-agencies`, and a set of glossary-style pages (`what-does-bcc-means`, `what-is-a-sales-qualified-lead`, `difference-between-lead-prospect`, …).

If a Lovable project were deleted, those designs are gone. Pulling them into this repo is the single highest-value follow-up.
